# Comment copier le lien direct d'un document 📎

Ce guide explique comment récupérer le **lien direct** (le lien de
téléchargement brut) d'un document stocké dans ce dépôt GitHub.
Aucune connaissance de GitHub n'est nécessaire : suivez simplement
les étapes.

## Étape 1 : ouvrir le dépôt

Ouvrez dans votre navigateur :

👉 https://github.com/Nicolas-Grosjean/acat/tree/main

## Étape 2 : naviguer jusqu'au document

1. Cliquez sur le **dossier de l'année** (par exemple `2026`).
2. Cliquez sur le **dossier du mois** (par exemple `10` pour octobre).

Vous voyez maintenant la liste des documents du mois.

## Étape 3 : copier le lien

La marche à suivre dépend du type de document :

### Cas 1 : document Word / LibreOffice (`.odt`, `.doc`, `.docx`)

1. Cliquez sur le **nom du document** (par exemple
   `Nov 2026 Tanz Ken cas.odt`).
   Une page s'ouvre avec un aperçu du fichier et, en haut à droite,
   des boutons **Download raw file** et **History**.
2. **Clic droit** sur le bouton **Download raw file**
   *(en français : « Télécharger le fichier brut »)*.
3. Choisissez **Copier l'adresse du lien**
   *(ou « Copy link address » / « Copier le lien » selon votre
   navigateur)*.

✅ C'est ce lien qui permet de télécharger directement le document.

### Cas 2 : document PDF (`.pdf`)

1. Cliquez sur le **nom du document**.
   Le PDF s'affiche directement dans le navigateur.
2. Copiez l'adresse dans la **barre d'adresse** en haut du navigateur
   (sélectionnez-la puis `Ctrl+C` ou `Cmd+C`).

✅ Ce lien ouvre le PDF directement : il est utilisable tel quel.

### Autres fichiers (images, etc.)

Même principe que le cas 1 : ouvrez le fichier, puis **clic droit**
sur le bouton **Download raw file** et choisissez
**Copier l'adresse du lien**.

## 💡 Astuce : vérifier le lien

Un lien direct se reconnaît facilement : il contient
`raw.githubusercontent.com` ou se termine par le nom exact du fichier
(par exemple `.../Nov%202026%20Tanz%20Ken%20cas.odt`).

Si le lien commence par `github.com/.../blob/...`, c'est le lien de la
*page* GitHub, pas du document lui-même. Il fonctionne aussi, mais il
ouvre la page GitHub au lieu de télécharger le fichier.
